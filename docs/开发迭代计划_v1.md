# AgentMatrix 前端打包 EXE + UI 美化 — 迭代开发计划

> **基线文档**: [前端打包EXE可行性分析报告_v3.1](file:///d:/AgentMatrix/docs/前端打包EXE可行性分析报告_v3.md)
> **总工期**: 17.5-25.5 个工作日，约 3.5-5 周
> **开发模式**: 迭代式，每个迭代交付一个完整功能模块或关键技术验证

---

## 迭代总览

```
迭代 0: 静态导出验证          (0.5天)  ← 前提条件，不过则终止
迭代 1: 最小后端打包验证       (0.5天)  ← 前提条件，不过则终止
迭代 2: 组件拆分 + Store 重构  (4-6天)  ← 核心改造
迭代 3: CSS 精简 + 功能裁减    (2-2.5天)  ← 视觉与体验
迭代 4: 错误边界 + 检测UI     (1.5-2.5天) ← 新增组件
迭代 5: Tauri 原型验证         (2-3天)   ← 关键里程碑
迭代 6: Tauri 完整集成         (3-4.5天) ← 系统整合
迭代 7: 后端打包 + 联调 + 安装器 (4-6天)  ← 最终交付
```

**迭代依赖关系**：

```
迭代 0 ──→ 迭代 1 ──→ 迭代 2 ──→ 迭代 3 ──→ 迭代 4
                                      │            │
                                      └────────────┼──→ 迭代 5 ──→ 迭代 6 ──→ 迭代 7
                                                   │
                                          (迭代 3/4 可并行于 5 的准备)
```

## 迭代 0：静态导出验证

### 目标

验证 Next.js 项目能否正常执行 `next export`，确认静态导出是可行的。

### 前提条件

- 后端服务正常运行（`localhost:8000`）
- Node.js 环境已配置

### 任务清单

| # | 任务 | 预计耗时 |
|---|------|----------|
| 0.1 | `next.config.js` 添加 `output: 'export'` | 10 min |
| 0.2 | `npm run build` 检查构建错误 | 15 min |
| 0.3 | `rimraf out && npm run build` 验证清空缓存后构建 | 15 min |
| 0.4 | 检查并替换 `next/image` 为 `<img>` | 30 min |
| 0.5 | `npx serve out` 浏览器打开，验证页面渲染 | 15 min |
| 0.6 | 验证 API 请求正常（发送测试任务） | 15 min |
| 0.7 | 验证 WebSocket 连接正常 | 10 min |
| 0.8 | 构造两次构建（第二次带内容变更），确认 Tauri 加载新文件 | 10 min |

### 完成标准

- [ ] `npm run build` 零错误退出
- [ ] `npx serve out` 页面正常渲染
- [ ] API 请求返回 200
- [ ] WebSocket 连接并接收事件
- [ ] 无 `next/image` 残留引用
- [ ] 两次构建后新文件被正确加载

### 风险与缓解

| 风险 | 等级 | 缓解 |
|------|------|------|
| `next/image` 大量使用导致替换工作量大 | 中 | 预先 grep 扫描 `next/image` 引用 |
| 静态导出后路由行为异常 | 低 | 仅一个页面 `/`，风险低 |

### 门禁

**任意一项失败 → 暂停，解决后再继续。如果静态导出根本不可行，则整个方案终止。**

### 预计耗时

0.5 天

| 干净虚拟机环境发现新的兼容性问题 | 中 | 提前准备 Windows 10/11 虚拟机镜像 |
| PyInstaller 打包后体积过大（>300MB） | 中 | 依赖精简是迭代 7 的核心任务 |
| 自动更新配置复杂，时间不够 | 低 | 可降级为基础安装器，自动更新延后到 v1.1 |

### 预计耗时

4-6 天
