# AgentMatrix 作品简介

> 用于毕业设计开题答辩 · 一页速览版

**拟定题目**
**面向单卡算力约束的 AgentMatrix 多智能体动态编排与降级机制设计与实现**

（备选：基于动态复杂度路由的 AgentMatrix 多智能体协同平台设计与实现）

**一句话说明**
在一台仅有 8GB 显存、纯本地运行、单模型实例的消费级电脑上，不依赖更大的模型，而是依靠**编排架构**，让一个 7B 小模型完成通常需要大模型才能完成的多跳任务。

---

## 一、要解决的问题

1. 云端大模型能力强，但存在**隐私外流、按量付费、离线不可用**三个硬伤；
2. 本地小模型（7B）单次生成质量不稳定，复杂任务易跑偏；
3. 业界主流解法是"在模型外面再包一层更大的模型或更重的编排框架"，但在**算力受限设备上根本跑不动**，且成本不可控。

**研究问题**：在算力、显存、模型规模三重受限的前提下，能否通过编排架构，让受限模型获得可用的任务完成质量？

---

## 二、系统做了什么（可现场演示）

一个打包好的桌面应用，无需部署。用户输入自然语言需求后，系统自动完成
**查资料 → 写初稿 → 自我评审 → 路由决策 → 结果整理** 五步，输出可直接导出的 Markdown / Word / PPT / 思维导图。

| 能力 | 说明 |
|---|---|
| 多轮对话 | 长期记忆 + 7 维用户画像，随使用自动演进 |
| 文档理解 | 上传 PPT / Word / Excel / 代码截图，自动转结构化 Markdown |
| 端云协同 | 无网可完全离线；配置云端 Key 时按需增强 |
| 弱化体验 | 自动识别用户不满，致歉并生成澄清问题后再答 |
| 多沙箱 | 不同用户数据彼此隔离 |

## 三、核心机制（技术重点）

### 1. 5-Agent 责任链
`Knowledge`（资料获取：视觉识别 / 联网检索 / 代码解析，不占用模型）→ `Writer`（唯一生成主力）→ `Review`（六维评分，默认规则引擎）→ `Judge`（纯规则路由，不调用模型）→ `Result`（整理与多格式导出）。
每个 Agent 职责单一、输入输出契约固定，任一环节失败都有明确降级语义。

### 2. 双阈值动态路由（核心创新点）
Judge 全程**不调用任何模型**，用纯规则矩阵决定"本地直出 / 云端局部润色 / 云端整段重写"：

| 任务难度 | 评审得分 | 决策 |
|---|---|---|
| < 0.50 | 任意 | 本地直出 |
| [0.50, 0.65) | ≥ 0.70 ／ < 0.70 | 本地直出 ／ 云端局部润色 |
| [0.65, 0.80) | ≥ 0.80 ／ < 0.80 | 本地直出 ／ 云端整段重写 |
| ≥ 0.80 | 任意 | 云端整段重写 |

**三个设计要点：**
1. 零 token 成本，路由结果**可复现、可解释**，不引入额外不确定性；
2. 引入"强信号词修正"，对抗小模型普遍低估任务难度的偏差；
3. 与技能知识库联动，命中已学技能时兜底阈值下调。

> 本作品的核心命题是：**知道什么时候"不该"调用模型。** 这也是与同类多智能体项目最大的区别。

### 3. 受限算力下的资源协调
主模型与视觉模型统一为 `qwen2.5vl:7b`，识别图片**无需卸载/重载模型，零切换开销**；进程级锁保证单卡串行调度，避免显存峰值叠加。

### 4. 自学习闭环（在建）
`Review 反馈 → 置信度过滤 → 生成技能补丁 → 审核应用`。骨架与数据结构已完备，正在打通补丁的实际落盘与生效链路。

## 四、已完成工作与验证证据

**① 安全加固（已完成并实测）**
实现本地 API 鉴权（REST Bearer + WebSocket 令牌）、CORS 白名单收敛、服务绑定回环地址、导出接口路径穿越修复（9 类恶意输入全部拦截为 400）、沙箱与技能标识符路径注入修复、安装包不再内嵌密钥文件。
实测 **14/15 项通过**（唯一未通过项由本机 Python 版本引起，与业务功能无关）。

**② 视觉能力实测（已完成）**
自建 4 张文档样本（PPT 含表格 / Word 含多级标题 / Excel 6×7 密集数字表 / 后者劣化至 1/6 像素并强 JPEG 压缩），走系统真实识别链路两轮测试：
**内容层面 8/8 全部正确、零幻觉**，42 个数字单元格全对；模型预热后单张耗时 5.3–6.1 秒。
同时定位到一处格式契约问题（输出偶被代码围栏包裹、标题层级漂移），修复方案已明确。

**③ 工程规模**
后端 202 个 Python 文件、约 3.26 万行；前端约 5,800 行；`backend/tests/` 下 35 个测试文件，其中含 30 题跨领域端到端评测台。
