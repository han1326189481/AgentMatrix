
========================================================================
                    AgentMatrix 快速启动指南
========================================================================

【一键启动方式】
----------------
直接双击项目根目录的:
    start.bat

或者在项目根目录打开 PowerShell，运行:
    .\start_all.ps1


【手动启动方式】
----------------
如果上面的方式不行，按以下步骤操作：

1. 打开 3 个独立的 PowerShell 窗口（或命令提示符）


窗口 1 - Ollama (已在运行):
-----------------------------
    # 保持当前窗口，不要关闭


窗口 2 - 后端服务:
------------------
    cd backend
    python -m uvicorn app.main:socket_app --host 0.0.0.0 --port 8000 --reload

    # 或者直接双击: backend/启动.bat


窗口 3 - 前端服务 (已在运行):
------------------------------
    cd frontend
    npm run dev


【访问地址】
------------
    前端界面:  http://localhost:3000
    后端API:   http://localhost:8000
    API文档:   http://localhost:8000/docs


【当前状态】
------------
    ✅ Ollama 正在运行 (端口 11435)
    ✅ 前端正在运行 (端口 3000)
    ❌ 后端未运行 (需要启动)
